# Django Products App

This project is a simple Django application created for a class activity.  
It demonstrates how to:

- Create a `Product` model with image support
- Link products to categories
- Insert and display products
- Register models in the Django admin
- Render product listings in templates
- (Optional) Create a Product Detail page

The project uses:
- Django
- Python (virtual environment recommended)
- Pillow (for image uploads)
